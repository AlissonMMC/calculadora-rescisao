ATUALIZAÇÃO V28

1. Os quatro tópicos complementares (Aluguel inteiro, Manutenção, Chaveiro e Seguros) usam um grid 2x2 compacto. Eles iniciam recolhidos para a tela ficar mais curta, mantendo o mesmo padrão visual e podendo ser abertos individualmente.

2. Seguros agora trabalham por parcela. Informe o valor de UMA parcela e, opcionalmente, a quantidade de parcelas extras. Ex.: R$ 100 + 2 extras = 3 parcelas = R$ 300.

3. Por padrão, cada seguro vem marcado para cobrança em DIAS FINAIS e ALUGUEL INTEIRO. Esses dois destinos podem ser desligados separadamente. Se ambos estiverem ligados, a parcela é considerada nos dois blocos, conforme a regra solicitada.

4. Os seguros selecionados para Dias Finais entram integralmente como parcela(s), sem rateio por 30. Os seguros selecionados para Aluguel Inteiro entram no valor calculado do aluguel inteiro.

5. Novos campos de parcelas/destinos são salvos no histórico e restaurados ao editar ou duplicar uma rescisão. Registros antigos continuam compatíveis: na ausência dos novos campos, os dois destinos começam marcados.

6. O estado de abertura dos tópicos ganhou uma nova chave V28 para que os quatro cards complementares não herdem o layout aberto da versão anterior.

Não substitua a pasta storage/dados permanentes ao atualizar o sistema.
