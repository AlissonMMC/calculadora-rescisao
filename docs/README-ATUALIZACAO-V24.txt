V24 — Ajustes finais de navegação e tema

1. O Gerador de Orçamentos deixou de usar o estado laranja sólido por padrão. Ele agora segue o mesmo comportamento visual dos demais itens do menu, com laranja apenas no estado ativo.
2. Cadastro de Prestadores recebeu tema escuro completo para a página.
3. Monitoramento recebeu tema escuro completo para a página.
4. A preferência de tema continua sendo a mesma do menu global e permanece salva no navegador.

Substitua a pasta orcamentos pela desta versão, preservando a pasta storage/dados existente do seu ambiente.
