ATUALIZAÇÃO V23 — MENU SUPERIOR PADRONIZADO

O sistema agora usa um único menu superior compartilhado por todas as telas de gestão.

Arquivo novo:
- nav_global.php — componente central do menu e do seletor de tema.

Telas integradas:
- Dashboard / Início
- Nova rescisão
- Gerador de Orçamentos
- Histórico de Rescisões
- Histórico de Orçamentos
- Cadastro de Prestadores
- Monitoramento
- Cadastro de Usuários
- Diagnóstico do Gerador
- Detalhe de rescisão

Recursos do menu:
- visual moderno, responsivo e consistente;
- item ativo destacado conforme a tela atual;
- botão de Gerador de Orçamentos sempre acessível;
- navegação horizontal em telas menores;
- identificação do usuário e perfil;
- alternância de modo claro/escuro usando a mesma preferência do sistema;
- logout centralizado;
- menu ocultado automaticamente na impressão.

INSTALAÇÃO
1. Faça backup da pasta atual.
2. Substitua os arquivos do sistema pelos arquivos desta versão.
3. Preserve a pasta storage e os dados persistentes existentes.
4. Não é necessário alterar banco de dados para esta atualização.

Atenção: esta versão altera somente a camada de navegação/tema das telas; não altera as regras de cálculo, processamento de orçamento, histórico ou geração de Excel/PDF.
