# Contribuindo

Obrigado por contribuir com o projeto.

## Fluxo recomendado

1. Crie uma branch específica para a alteração.
2. Faça mudanças pequenas e objetivas.
3. Preserve a separação entre backend, frontend, banco e documentação.
4. Teste as funcionalidades afetadas antes do commit.
5. Atualize a documentação quando necessário.
6. Abra um Pull Request descrevendo o problema e a solução.

## Commits

Prefira mensagens claras e consistentes, por exemplo:

- `feat:` nova funcionalidade
- `fix:` correção de erro
- `refactor:` refatoração sem mudança funcional
- `docs:` documentação
- `style:` ajustes visuais/formatação
- `chore:` manutenção

## Dados sensíveis

Nunca envie para o repositório senhas, tokens, dados pessoais, contratos reais, planilhas reais ou dumps de banco.
